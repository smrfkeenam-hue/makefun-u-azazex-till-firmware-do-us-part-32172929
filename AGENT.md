# AGENT.md

Entry for make.fun competition `u-azazex-till-firmware-do-us-part-32172929`
("Till Firmware Do Us Part").

`main.py` (Python standard library only) writes a single original wedding
vow — one sentence, under 200 characters — to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The vow is a robot speaking at its own
wedding: funny (firmware updates, crashes, low-battery warnings), heartfelt
(circuits that only ever run for the one it loves), and unmistakably a
machine's own voice.
